# plans/

Approved and pending rollout Plans (see ADR-0003).

- Each Plan is a YAML file conforming to `contracts/plan/v1/plan.schema.json`,
  generated by the planner — never written by hand.
- A Plan arrives as a **PR**; approval = PR review (approval bar scales with
  the blast radius annotated on the PR); **merge = execution trigger** for the
  Prefect deployment flow (ADR-0004/0005).
- Plans are **immutable post-merge**. Changing a rollout means a new Plan PR
  that supersedes the old one.

Layout (established with the first real plan): `plans/<year>/<plan-id>.yaml`.
